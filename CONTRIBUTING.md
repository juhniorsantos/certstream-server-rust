# Contributing

Bug reports and pull requests are welcome. Open an [issue](https://github.com/reloading01/certstream-server-rust/issues) first for larger changes.

```bash
cargo test --release
```

- Add a test for bug fixes.
- Run changes that touch CT log fetching against live logs; unit tests do not cover operator behaviour.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages.

You can also [sponsor the project](https://github.com/sponsors/reloading01).
